## 🐍 Как запустить? 🏃‍♂️💨

```bash
# 1️⃣ Клонируем репозиторий 📥
git clone https://github.com/ВАШ_НИК/calculator.git

# 2️⃣ Заходим в папку 📂
cd calculator

# 3️⃣ Запускаем! 🎬
python calculator.py
```

> ⚠️ **Важно:** нужен установленный **Python 3.x** 🐍 (проверить: `python --version`)
